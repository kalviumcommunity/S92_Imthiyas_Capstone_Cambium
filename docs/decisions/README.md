# Architecture Decision Records (ADRs)
## `docs/decisions/`

All authoritative Architecture Decision Records (`ADR 0001` through `ADR 0007`) are maintained in one Single Source of Truth at [`docs/architecture/adr/README.md`](../architecture/adr/README.md) to prevent index drift.

> Format: Michael Nygard ADR format (Context, Decision, Alternatives Considered, Consequences, Risks, Revisit Conditions). Historical early-sprint rationale reconstructed from implementation where inline design notes were absent is explicitly labeled.
