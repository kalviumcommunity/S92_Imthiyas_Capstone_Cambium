# Cambium Research — Master Data Inventory

## 1. Purpose
Documents actual data categories stored or processed across `server/src/` (PostgreSQL + pgvector + Redis + disk uploads) and `client/` browser storage.

## 2. Inventory by Category

| Category | Example Fields Observed | Source | Primary Storage | Derived Data Generated | AI Involvement | Classification |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Identity & Authentication** | `id`, `username`, `email`, `passwordHash`, `fullName`, `role`, `institution`, `organizationId`, `departmentId` | User sign-up, SSO/SAML, Google OAuth | PostgreSQL (`users`), Redis session/blacklist cache, HttpOnly cookie (`cambium_refresh_token`), `localStorage` (`cambium_token`, `cambium_user`) | JWT claims, password bcrypt hashes | `institution` / stage may optionally contextualize eligibility checks | `CLASS 4 (RESTRICTED)` (`passwordHash`, tokens) / `CLASS 3 (CONFIDENTIAL)` (`email`, profile) |
| **Scholarly Interests & Bookmarks** | `research_interests`, `user_interests`, `bookmarks` (`opportunityId`, `userId`) | User profile onboarding & UI bookmark toggles | PostgreSQL (`bookmarks`, `research_interests`) | Recommendation matching context | Optional keyword alignment | `CLASS 3 (CONFIDENTIAL)` (user bookmarks) / `CLASS 1` (taxonomy tags) |
| **Public Research Opportunities** | `title`, `type`, `organization`, `deadline`, `description`, `link`, `tags`, 768-dim embedding | External crawlers (arXiv, DOAJ, OpenAlex) or authenticated creators | PostgreSQL (`research_opportunities` + pgvector HNSW index) | Vector embeddings, RRF ranking scores | Semantic embedding & RAG retrieval | `CLASS 1 (PUBLIC)` |
| **Collaborative Project Workspaces** | `group_projects`, `project_members` (`CRediTRole`), `project_activity_logs`, `workspace_comments`, `chat_messages` | Workspace owners & invited researchers | PostgreSQL + Socket.IO memory/Redis adapter | Activity timelines, outbox events | Optional workspace copilot assistance | `CLASS 3 (CONFIDENTIAL)` when `PRIVATE` or `LAB_ONLY` |
| **Institutional Grants, Budgets & Compliance** | `organizations`, `departments`, `proposals`, `proposal_revisions`, `proposal_reviews`, `funding_accounts`, `budget_line_items`, `expense_requests`, `compliance_protocols` | Institutional officers, reviewers, PIs | PostgreSQL (`institution` module tables) | Revision diffs, review scores | Restricted by default unless explicitly authorized | `CLASS 4 (RESTRICTED)` / `CLASS 3 (CONFIDENTIAL)` |
| **Uploaded Research Artifacts** | `id`, `originalName`, `sanitizedName`, `mimeType`, `sizeBytes`, `sha256Hash`, `uploaderId`, `filePath` | Researcher file uploads (`.pdf`, `.docx`, `.csv`, `.xlsx`, `.bib`, `.tex`, `.json`) | Server filesystem (`uploads/artifacts/`), `localStorage` (`cambium_workspace_artifacts`) | OCR extracted tables/text (`PdfOcrService`), `DocumentParserService` semantic chunks & embeddings | RAG document snippet analysis (must respect classification & consent) | `CLASS 3 (CONFIDENTIAL)` default; `CLASS 4 (RESTRICTED)` when marked |
| **AI Prompts & Completions** | `messages`, `documentSnippet`, `persona`, `prefix` | User input in Agentic Reader & Autocomplete Copilot | Transient server memory / outbound HTTPS request to Gemini API (no dedicated chat history table observed) | Local fallback synthesis / streamed SSE chunks | Sent to Google Gemini API (`generativelanguage.googleapis.com`) when API key active | `CLASS 3 (CONFIDENTIAL)` |
| **Audit, Telemetry & Outbox** | `audit_logs` (`entityName`, `action`, `userId`, `payload`, `previousHash`, `currentHash`), OpenTelemetry trace spans (`TelemetryService`) | Global interceptors (`AuditInterceptor`, `TelemetryInterceptor`) | PostgreSQL (`audit_logs`, `outbox_events`), in-memory span buffer (`maxBufferSize = 500`) | SHA-256 hash chain, latency p50–p99 metrics | None | `CLASS 2 (INTERNAL)` / `CLASS 3` if unredacted body logged |
| **Consent & Privacy Governance** *(Added Program 09)* | `user_privacy_preferences`, `consent_records` (`purpose`, `noticeVersion`, `action`), `privacy_requests` (`requestType`, `status`) | User actions in cookie banner & Settings Privacy desk | PostgreSQL + client `localStorage` (`cambium-cookie-consent`) | Audit receipts | Controls whether AI/analytics run | `CLASS 4 (RESTRICTED)` / `CLASS 3` |
