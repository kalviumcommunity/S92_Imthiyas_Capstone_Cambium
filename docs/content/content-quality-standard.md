# Cambium Content Quality Standard
## Editorial Guidelines, UX Microcopy Rules & Anti-AI-Slop Gate

---

### Purpose of this Document
This standard governs all user-facing text, labels, messages, documentation, and microcopy across the Cambium Research platform. Every pull request and feature addition must comply with these guidelines.

---

## 1. Core Principles

1. **Every word must justify its existence**: If an interface element, badge, or sentence can be removed without losing functionality or clarity, delete it.
2. **Demonstrate credibility; never fabricate it**: Never display invented user statistics, fictional institutional affiliations, fake testimonials, or unsupported security badges.
3. **Restraint over hyperbole**: Avoid exaggerated marketing vocabulary (*"revolutionary"*, *"seamless"*, *"next-generation"*, *"supercharge"*, *"unleash"*).
4. **Contextual utility**: Loading, empty, and error states must explain the actual system event and provide a clear recovery path. Never comment on animations, UI physics, or fictional AI processes.
5. **Human rhythm**: Avoid repetitive em dashes (*"—"*), artificial contrast tropes (*"not just X, but Y"*), and symmetrical three-part lists.

## 3. The 10-Point Feature Completion Gate

Before any component or page is merged, its copy must pass all 10 checks:

1. **Purpose**: Does this text serve a genuine user need?
2. **Clarity**: Can the intended researcher understand it immediately?
3. **Specificity**: Does it describe Cambium's actual software capabilities?
4. **Accuracy**: Is every technical claim backed by code?
5. **Credibility**: Are all statistics and numbers verifiable?
6. **Naturalness**: Does it read like professional, human-crafted prose?
7. **Concision**: Have filler words, buzzwords, and unnecessary em dashes been removed?
8. **Consistency**: Does it adhere to the Terminology Dictionary?
9. **Accessibility**: Are form labels, ARIA tags, and error instructions descriptive?
10. **Actionability**: Do buttons describe the concrete action taken upon clicking?
