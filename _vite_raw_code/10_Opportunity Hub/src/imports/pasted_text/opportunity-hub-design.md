Design Page 08 of Cambium:

OPPORTUNITY HUB

Cambium is the world's first Research Operating System.

This page must feel like one of Cambium's flagship experiences.

Do NOT create a generic job board.

Do NOT create a generic grant database.

Do NOT create a conference listing website.

Do NOT create a conventional search-results page.

Instead, create an intelligent academic opportunity environment where
researchers can understand:

• What opportunities exist?
• Which opportunities are relevant to me?
• Why are they relevant?
• What should I apply to?
• What deadlines are approaching?
• Which opportunities fit my research?
• Which conferences should I consider?
• Which journals or calls are worth watching?
• What opportunities have I saved?
• What opportunities am I already pursuing?

══════════════════════════════════════════════════════════════════════

Create a generic grant database.

Create a giant card grid.

Create a generic dashboard.

Use KPI cards as the primary experience.

Use fake statistics.

Use generic SaaS illustrations.

Use stock scientist photography.

Use robots or AI brains.

Use purple AI gradients.

Use excessive glassmorphism.

Use excessive rounded cards.

Make every opportunity look equally important.
