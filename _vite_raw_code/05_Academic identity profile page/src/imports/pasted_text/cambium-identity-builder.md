CAMBIUM — CREATE YOUR ACADEMIC IDENTITY
PAGE 03 — PRODUCTION-QUALITY DESKTOP UI DESIGN

Create a complete, premium, production-quality desktop web application screen for CAMBIUM.

Cambium is a Research Operating System for researchers, scholars, academics, research labs and research-focused professionals.

This is NOT a generic SaaS onboarding flow.

This is NOT a dashboard.

This is NOT an AI profile generator.

This page is the user's first opportunity to create their permanent academic identity inside Cambium.

==================================================
DESIGN OBJECTIVE
==================================================

Create a sophisticated "Create Your Academic Identity" experience.

The core emotional response should be:

"This actually represents me as a researcher."

The experience should feel like a combination of:

• LinkedIn-level professional identity
• Notion-level flexibility
• GitHub-level structured information
• Linear-level clarity
• Stripe-level polish
• Apple-level simplicity
• modern academic software credibility

DO NOT copy any of these products.

Create an original Cambium visual language.

The final design should look like a real product that could ship.

==================================================
PRIMARY QUESTION
==================================================

The page should answer:

"Who am I as a researcher?"

The user is manually building their academic identity.

The researcher controls the information.

Do not automatically generate their profile.
